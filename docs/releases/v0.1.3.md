- 修复 macOS/Linux 上独立虚拟环境被误判为宿主机环境，导致 Python 依赖与 `yt-dlp` 安装完成后仍回到待安装状态的问题，并补充 macOS 打包 Python 二进制签名 Entitlements。
- 优化国内网络环境的依赖与模型下载体验：Whisper `large-v3-turbo` 切换至 ModelScope 可用镜像并修正精确文件大小校验，PyPI 与 PyTorch Wheels 默认优先选择阿里云/清华国内源并支持源连通性探测与失败源临时避让，Windows FFmpeg 支持国内镜像归档回退，并在资源设置页实时显示安装与下载日志。
- 修复计算加速环境检测与自动修复（#206）：基于独立虚拟环境探测真实 CUDA / ROCm / MPS 运算能力；当 GPU 主机误装了 CPU-only PyTorch（如旧版安装的 `torch==2.15.0` 等不匹配版本）时，清晰标注并支持一键自动重装匹配硬件方案的 `torch`、`torchaudio` 与 `torchcodec`。
- 修复 Whisper 在清除瞬时/空白语音分段时留下空占位分段，导致后续校验报错 `Whisper returned an empty or invalid speech segment.` 的问题。
- 为 VoxCPM2 配音子进程新增模型加载设备与逐句生成进度事件，运行日志与进度展示可实时反馈当前计算设备及配音进度。
